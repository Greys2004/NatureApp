## 🌌 About the project

An Angular application for organizing parks, trails and destinations, with mapping tools and an AI-assisted place analysis screen.

## ✨ Main features

- Park and trail management through a web interface
- Interactive geospatial features through Mapbox GL
- AI-assisted place analysis, categories and accessibility indicators (shown in the supplied screenshot)
- Separate ASP.NET Core backend in NatureApi

## 🛠️ Technology

`Angular 20` · `TypeScript` · `Mapbox GL` · `NG-ZORRO` · `Docker`

## 🚀 Getting started

```bash
npm ci
npm start
```

Use the Node.js version supported by the project; frontend features that call an API require its URL and environment configuration. For GeoMap, create `backend/.env` based on `backend/.env.example` and configure MongoDB.
